# Uczelniany Dziennik Elektroniczny
 
Desktopowa aplikacja w C# (WPF) do zarządzania danymi uczelni – studentami, prowadzącymi, kierunkami i ocenami.
 
## Funkcjonalności
 
- Zarządzanie studentami i prowadzącymi (dodawanie, usuwanie, przeglądanie)
- Obsługa kierunków i semestrów
- Wystawianie i przeglądanie ocen
- Obliczanie średniej ocen studenta
- Sortowanie studentów i prowadzących (alfabetycznie, po tytule naukowym)
- Zapis i odczyt danych w formacie XML
- Walidacja PESEL i ocen (skala 2–5)
## Technologie
 
- C# / WPF (.NET)
- MSTest – testy jednostkowe
- Serializacja XML
## Uruchomienie
 
1. Sklonuj repozytorium
2. Otwórz `dziennik.sln` w Visual Studio
3. Ustaw `DziennikGUI` jako projekt startowy
4. Uruchom (F5)
Aplikacja ładuje przykładowe dane testowe przy starcie.
